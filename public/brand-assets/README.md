# Pickle-lo Brand Asset Pack

Transparent PNG assets generated from the supplied Pickle-lo brand exploration board.

## Files

- `logo-pickle-lo-primary.png` — primary horizontal wordmark
- `mark-pickle-lo-p.png` — standalone `P` brand mark
- `mascot-pickle-lo-hero.png` — neutral/confident hero pose
- `mascot-pickle-lo-ready.png` — ready-to-play pose
- `mascot-pickle-lo-celebrate.png` — raised-fist celebration pose
- `mascot-pickle-lo-good-game.png` — thumbs-up success pose
- `mascot-pickle-lo-thinking.png` — planning/help pose with pickleball
- `favicon/favicon.ico` — multi-size browser fallback and shortcut icon
- `favicon/favicon-16x16.png` — compact browser-tab icon
- `favicon/favicon-32x32.png` — standard browser-tab and bookmark icon
- `favicon/favicon-48x48.png` — high-density browser icon
- `favicon/favicon-256x256.png` — high-resolution bookmark/icon source

All PNG files use RGBA transparency and contain no background surface or cast shadow.

## Recommended app usage

- Use the primary logo in navigation, launch screens, and marketing layouts.
- Use the standalone mark for compact brand placements; place it inside your own app-icon tile when needed.
- Use `hero` for onboarding and landing pages.
- Use `ready` for empty states related to games, events, or scheduling.
- Use `celebrate` and `good-game` for success states.
- Use `thinking` for help, planning, setup, and pending states.
- Use `favicon.ico` as the broad browser fallback and shortcut icon.
- Provide the 16px, 32px, and 48px PNG variants through Next.js metadata so browsers can choose the closest tab/bookmark size.
- Keep the 256px PNG available for high-resolution browser surfaces and as the source for future manifest/app-icon derivatives.
- Do not use favicon files as the in-app wordmark, navigation logo, avatar, or mascot; use `logo-pickle-lo-primary.png` or `mark-pickle-lo-p.png` for those placements.
- Do not upscale the small favicon variants or generate new derivatives without documenting the reason.

## Important

These assets are AI-generated recreations from a draft composite board, not deterministic crops from original layered artwork. Review and approve character consistency, spelling, ownership, and trademark usage before public production release.
